# Contributing to EngiDock Cheatsheets

Thanks for helping keep these accurate and useful.

## Adding a new cheatsheet

1. Create a folder under the matching topic (or a new one if it doesn't exist yet).
2. Add a `README.md` inside it using the existing cheatsheets as a format example: short sections, code blocks, no long paragraphs.
3. Keep each entry copy-paste-ready — one command or snippet per block, with a one-line comment above it explaining when to use it.
4. Open a pull request. Briefly note what the cheatsheet covers and link the related engidock.com course/article if there is one.

## Fixing an existing cheatsheet

Open a pull request with the correction. If it's a small fix (typo, outdated flag), no need to explain — the diff speaks for itself.

## Style

- Use `##` headers for sections, not `#` (the title already uses `#`).
- Prefer tables for command/flag comparisons.
- Link back to the relevant engidock.com page where useful.
