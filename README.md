# EngiDock Cheatsheets

Quick-reference cheatsheets for the courses on [engidock.com](https://www.engidock.com/cheatsheets) — kubectl commands, Terraform HCL, git workflows, SQL queries, Excel formulas, and more. Each topic folder has a single `README.md` with copy-paste-ready commands, snippets, and quick reference tables, organized the same way as the cheatsheet on the site.
