# EngiDock Cheatsheets

Quick-reference cheatsheets for the topics covered on [engidock.com](https://www.engidock.com/cheatsheets).

## Contents

- [`kubernetes/`](./kubernetes) — kubectl commands, manifests, troubleshooting checklists
- [`python/`](./python) — scripting patterns, common errors, debugging shortcuts
- [`cybersecurity/`](./cybersecurity) — fundamentals, common attack patterns, hardening checklists

Each folder has its own `README.md` with the actual cheatsheet content.

## Using these

Pick a topic folder, grab what you need, and star the repo if it saves you time. For the full course that goes with a cheatsheet, check [engidock.com](https://www.engidock.com).

## Contributing

Spotted an outdated command or want to add a new topic? Open a pull request — keep entries short, scannable, and copy-paste-ready. See [`CONTRIBUTING.md`](./CONTRIBUTING.md).
